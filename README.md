# vendyluo/tap

Homebrew formulae and release archives for tools by vendyluo.

```sh
brew install vendyluo/tap/jolt
```

| Formula | What it is | Platforms |
| --- | --- | --- |
| `jolt` | A coding agent for the terminal that reports whether the work really finished. Proprietary; the release includes its own JDK 27. | macOS, Apple silicon |

Each formula's archive is attached to a release of this repository named after it, such as `jolt-v0.13.0`.
